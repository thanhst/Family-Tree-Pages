# Family Tree

Online: https://thanhst.github.io/Family-Tree-Pages/

Shared family JSON lives on branch `codex/shared-data`, file `family-tree.json`. The app reads it through GitHub API when opened or refreshed. Editors need their own repository write permission and token; no token is embedded in the app.

The shared family dataset is public by owner request. Application accounts, password hashes and sessions are not published. The empty JSON on main is only the optional local-mode seed.
